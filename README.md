# Probability and Statistics Practice

A collection of university coursework, coding exercises, and self-study materials focused on statistics and probability using **R and Python**.

This repository documents my practice with statistical concepts, data analysis, visualization, and simulation.

## Contents

### R Learning (`r-learning/`)

Scripts created while learning R through online tutorials and lecture materials.

Topics include:
- R fundamentals and data structures
- Data manipulation and descriptive statistics
- Data visualization with base R and ggplot2
- The apply family of functions
- Basic probability distributions

### R Coursework (`r-coursework/`)

Assignments from university statistics and probability courses, covering:

- Exploratory data analysis
- Probability distributions and random variables
- Statistical simulation and sampling
- Joint distributions and correlation
- Central Limit Theorem
- Hypothesis testing and permutation tests
- Statistical estimation

### Python Book Exercises (`python-book-exercises/`)

Jupyter notebooks containing exercises and experiments based on selected chapters of *Modern Statistics: Intuition, Math, Python, R* by Mike X Cohen.

Topics include descriptive statistics, data transformations, probability distributions, the Law of Large Numbers, the Central Limit Theorem, hypothesis testing, and correlation.

Book reference: [Official GitHub Repository](https://github.com/mikexcohen/Statistics_book)

## Tools

- **R:** Base R, ggplot2, dplyr, and other statistical packages
- **Python:** NumPy, SciPy, Matplotlib, pandas, and scikit-learn
- **Jupyter Notebook**
